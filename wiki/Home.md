# Fractals Web

**[Open the Fractal Lab](https://fractals.ai-aarti.com/)**

Fractals Web is a visual science workbench for exploring fractals, measuring image complexity, comparing visual evidence, and retaining a reproducible record of the work.

## Start with one task

1. **[Create a fractal](https://fractals.ai-aarti.com/workbench/fractals)** — explore mathematical rules visually.
2. **[Measure an image](https://fractals.ai-aarti.com/workbench/box-count)** — estimate complexity in a selected region with box counting.
3. **[Compare evidence](https://fractals.ai-aarti.com/workbench/compare)** — assess two visual methods side by side.

## What the workbench preserves

- The visual result and the inputs that produced it
- Measurement settings and fit-quality context
- Run history that can be reviewed or exported

## Biomedical research scope

The tumor-complexity workflow is an educational research prototype. It explores whether interpretable fractal-morphology measurements could complement AI localization. It is **not** a diagnostic, prognostic, treatment, or clinically validated tool.

Read the **[tumor-complexity validation plan](https://github.com/aartisr/fractals-web/blob/main/docs/tumor-complexity-validation-plan.md)** for the evidence required to make any stronger claim.
